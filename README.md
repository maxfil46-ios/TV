# Пульт Яндекс ТВ для iPhone

Локальная веб‑страница с крупными кнопками, которую можно добавить на экран «Домой» iPhone. Она обращается к телевизору через ADB по Wi‑Fi. Компьютер служит мостом, поэтому сервер должен работать, а ТВ и компьютер — находиться в одной домашней сети.

## Запуск

1. Включите на телевизоре «Отладка по сети» и убедитесь, что адрес ТВ — `192.168.1.167`, порт — `5555`. После перезагрузки или отключения отладки может понадобиться включить её снова.
2. Запустите `start-remote.bat` на этом компьютере.
3. Откройте показанный адрес `http://IP-КОМПЬЮТЕРА:8765` в Safari на iPhone и введите PIN из окна сервера.
4. В Safari нажмите «Поделиться» → «На экран Домой».

Для выключения закройте окно сервера. Кнопки отправляют только разрешённые ADB keyevent-команды; PIN меняется при каждом старте. Не открывайте порт `8765` на роутере наружу.

Примечание: управление Алисой возможно кнопкой, но голосовой ввод с микрофона iPhone пока не реализован. Названия пакетов приложений на конкретной прошивке могут отличаться; кнопки запуска используют стандартные пакеты и при несовпадении могут не сработать.
